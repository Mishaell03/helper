# Установка и удаление Helper

Сборка установщика: `build-installer.cmd` (нужен Inno Setup 6.3+).
Готовый installer и portable ZIP: `installer/output/v<версия>/`.

## Ярлык запуска

Установщик автоматически создаёт ярлык Helper на рабочем столе текущего
пользователя с сочетанием **Ctrl+Shift+F1**, а также ярлык в меню «Пуск».
Сочетание обрабатывает оболочка Windows: оно запускает закрытое приложение.
Если Helper уже работает, повторный запуск показывает существующий экземпляр.
Это отдельное сочетание от настраиваемой горячей клавиши показа/скрытия внутри
Helper. При конфликте с другим ПО запуск сочетанием не гарантируется.

Обычная команда `flutter build windows` и распаковка portable ZIP не устанавливают
ярлыки рабочего стола: для автоматического ярлыка используйте установщик.

## Uninstall

Перед удалением uninstaller останавливает Helper из **своего** каталога установки,
включая скрытое окно и активный автоввод. Сначала посылается нативная команда
завершения; если процесс завис, через четыре секунды он завершается принудительно.
Также останавливается `generator.exe` из этого каталога. Другая portable-копия
Helper не завершается только из-за совпадения имени процесса.

Далее удаляются ярлыки, относящаяся к этой установке запись автозапуска и
**вся папка установки**, включая добавленные вручную файлы и внешний модуль.
Не храните в папке установки личные документы. Установка в корень диска или
непосредственно в основные системные/пользовательские каталоги запрещена.
Если остановить процесс не получилось, удаление отменяется, а не продолжается
частично.

Библиотека и настройки в `%LOCALAPPDATA%\Helper`, а также результаты, сохранённые
вне папки программы, не удаляются. Для очистки библиотеки используйте
«Удалить все данные приложения» перед uninstall.

Проверка остановки на временных процессах без удаления реальной установки:
`powershell -NoProfile -ExecutionPolicy Bypass -File tool/test_windows_uninstall.ps1`.
